## Day 1: Cloud Computing Fundamentals

- What cloud computing means: on-demand resources over the internet with pay-as-you-go pricing
- Service models: IaaS, PaaS and SaaS
- Deployment models: public, private and hybrid cloud
- Core advantages and key terms

## Day 2: AWS Fundamentals

- **Shared Responsibility Model:** security OF the cloud (AWS) vs security IN the cloud (customer), shared and inherited controls
- **EC2 instance types and pricing:** instance families, naming convention, burstable instances, On-Demand, Savings Plans, Reserved, Spot, Dedicated Hosts and Capacity Reservations
- **AMI (Amazon Machine Image):** components, sources, lifecycle, Region rules, AMI vs snapshot vs launch template
- **IAM:** root user, users, groups, roles, policies, evaluation logic, MFA and best practices
